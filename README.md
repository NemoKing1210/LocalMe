# LocalMe

A messenger for your local network. It finds the other computers running it, with no server
and no configuration, and exchanges text messages with them.

Built with Tauri 2 (Rust) and Vue 3.

## Status

Under construction. The architecture is fixed in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md);
the protocol, storage, discovery and service layers are being implemented in vertical slices.
